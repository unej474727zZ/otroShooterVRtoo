VR CQB Tactical Shooter

High Performance Mobile VR CQB Starter Kit with Native Bluetooth Gamepad Bridge & Tactical Radar for Android.

1. Overview

This project is a complete, production-ready VR tactical CQB shooter template built specifically for Android devices (Google Cardboard, VR Headsets, and VR mobile cases). It bridges an ultra-optimized WebXR/A-Frame 3D engine with native Android Java code, delivering steady 60 FPS gameplay with zero complex native C++ overhead.

Highlight: Includes a proprietary Native Android Gamepad Bridge that solves the dreaded thumbstick axis deadzone and compatibility issues on generic Bluetooth controllers (X3, Ipega, Xbox, PlayStation).

2. Key Features

🎮 Native Gamepad Bridge

Smooth joystick steering and look controls via Android JavascriptInterface. Eliminates browser input lag.

📡 5-Point Tactical Radar

Diegetic, borderless proximity sensor. Blue central player dot + 4 red enemy dots tracking angle and distance in real time.

🤖 Dynamic Enemy AI

Wave-based enemies with Seeker/Hunter and Patroller roles. Includes a 750ms tactical reaction grace window with weapon sound cues.

🎯 Dual Hitbox System

Separate head and body collision shapes with distinct damage multipliers (Headshot 3x critical damage).

🔊 Spatial Audio & Night Vision

Positional sound effects, low-footstep warnings, and glowing tactical dual-LED night vision visors on enemy helmets.

⚡ 60 FPS Low Poly Engine

Optimized WebP textures, compressed GLB models, and shader pre-compilation to prevent mobile VR stutter.

3. Android Studio Setup

Follow these steps to compile and run the project:

Prerequisites

• Android Studio Hedgehog / Iguana / Ladybug or newer.
• Android SDK 34 (Android 14) or newer.
• Java JDK 17 or JDK 21.

Step-by-Step Build Instructions

1. Open Project: Launch Android Studio, click File -> Open, and select the Source_Code folder.

2. Sync Gradle: Allow Android Studio to automatically download dependencies and sync Gradle.

3. Connect Device: Connect your Android smartphone via USB with USB Debugging enabled in Developer Options.

4. Run or Build APK: Click the green Run (Shift + F10) button, or select Build -> Build Bundle(s) / APK(s) -> Build APK(s).

5. Command Line Build (Alternative):

./gradlew assembleDebug

Your finished APK will be generated at: app/build/outputs/apk/debug/app-debug.apk

5. Reskin & Customization Guide

A. Changing the Package Name & App Title

1. Open app/build.gradle and modify the applicationId:

defaultConfig {
    applicationId "com.yourcompany.vrshooter"
    minSdkVersion 24
    targetSdkVersion 34
    ...
}

2. Open app/src/main/res/values/strings.xml and update your game name:

<string name="app_name">Your Game Title</string>

3. Replace app icons inside app/src/main/res/mipmap-*/ic_launcher.png.

B. Tweaking Game Balance & Mechanics

All core gameplay logic is cleanly organized inside app/src/main/assets/index.html:

• Player Speed & Weapon Ammo: Look for weapon-system around line 1610 (change maxAmmo: 36, fireRate: 100).

• Enemy Numbers & Difficulty: Look for npc-manager (adjust activeCount: 4 or targetKills: 30).

• Enemy Reaction Window: In npc-ai, adjust the 750ms reaction grace delay before they open fire.

C. Replacing 3D Models

All 3D assets live in app/src/main/assets/ as standard .glb files:

• Building/Map: Replace low-poly_industrial_building.glb with your own 3D level.

• Weapon: Replace m4a1rifle.glb with any standard GLB gun model.

• Character: Compatible with any Adobe Mixamo humanoid avatar export.

6. Technical Architecture

Understanding how the hybrid WebXR-Android bridge operates:

[ Bluetooth Gamepad (Hardware) ]
              │
              ▼
[ Android Activity: onGenericMotionEvent / onKeyDown ]
              │
              ▼
[ Native JavascriptInterface: GamepadInterface ]
              │ (Instant polling @ 60 FPS)
              ▼
[ A-Frame Engine: gamepad-fps Component (Three.js) ]
              │
              ▼
[ WebXR Stereo VR View / Canvas Rendering ]

This bypasses erratic browser Gamepad API implementations on Android, ensuring 100% controller reliability regardless of phone manufacturer.
